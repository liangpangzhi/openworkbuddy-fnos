# 03 · 安装与使用

## 安装

### 方式一：应用中心手动安装（推荐）

飞牛「应用中心 → 右上角 手动安装」→ 选择 `.fpk` → 按向导装到某个存储卷。

### 方式二：命令行

```bash
# 预演（上传并检查，不真正安装）
fnos-cli app install-fpk ./openworkbuddy-0.17.5-1.fpk --volume-id 1 --dry-run --yes

# 安装
fnos-cli app install-fpk ./openworkbuddy-0.17.5-1.fpk --volume-id 1 --yes
```

首次安装约 40 秒 ~ 2 分钟（含上传 160MB、解包、导入 205MB 镜像），
容器首次启动另需约 4 分钟（试装 python/中文字体），之后就是秒起。

## 进入系统

- 飞牛桌面会出现「OpenWorkBuddy」图标，点击打开 `http://<NAS-IP>:3800`
- 也可以直接浏览器访问 `http://<NAS-IP>:3800`

**第一个注册的账号就是管理员**，注册后即可使用。

## 接入各类主流 AI

应用是 BYOK（自带 Key）架构，进系统后走 **设置 → 模型**，选服务商、填 API Key 和型号，
点「测试连接」通过后就能下任务。内置预设：

| 服务商 | base_url |
| --- | --- |
| DeepSeek | `https://api.deepseek.com/v1` |
| 通义千问 Qwen | `https://dashscope.aliyuncs.com/compatible-mode/v1` |
| 智谱 GLM | `https://open.bigmodel.cn/api/paas/v4` |
| Kimi | `https://api.moonshot.cn/v1` |
| 豆包（火山方舟） | `https://ark.cn-beijing.volces.com/api/v3` |
| OpenAI | `https://api.openai.com/v1` |
| Anthropic Claude | （官方 SDK） |
| OpenRouter | `https://openrouter.ai/api/v1` |
| Ollama 本地 | `http://host:11434/v1` |

另外支持「自定义渠道」：任何 OpenAI 兼容接口（自建 vLLM / 企业中转 / 其他国产模型）
填 base_url + 型号 + Key 即可。Key 只写在 NAS 本地的 `config.json` 里，不外发。

## 数据与文件

| 位置 | 内容 |
| --- | --- |
| `/var/apps/<appname>/shares/<appname>/` | 全部可写数据（账号、会话、配置、成果文件、工作区） |
| `/var/apps/<appname>/target/docker/app/` | 应用代码（只读使用，升级会被替换） |

共享目录会在飞牛「文件管理」里可见，AI 产出的 PPT/Word/Excel 可以直接从那里取。
`卸载应用不会删除共享目录`，重新安装数据还在。

## 端口

默认 `3800`。要改：

1. `fpk-src/app/docker/docker-compose.yaml` 的 `ports` 和 `PORT` 环境变量
2. `fpk-src/manifest` 的 `service_port`
3. `fpk-src/app/ui/config` 的 `port`

三处要一致。

## 启停 / 升级 / 卸载

- 启停：应用中心里的开关，或 `fnos-cli app start|stop <appname> --yes`
- 升级：安装更高版本号的 `.fpk`，`cmd/upgrade_callback` 会重新拉起容器
- 卸载：应用中心卸载，或 `fnos-cli app uninstall <appname> --yes`
  （`uninstall_init` 会兜底移除容器；数据目录保留）

## 首次使用建议

按上游 README 的三分钟试用流程走一遍：设置 → 模型填好 Key → 首页粘贴任务：

```
请做一份 4 页的项目汇报 PPT，保存为 project-update.pptx。
…（四页内容要求）…
要求：16:9、中文、简洁商务风；正文使用可编辑文本。
```

成功标准：磁盘上出现非空的 `project-update.pptx`，PowerPoint / WPS / LibreOffice 能打开且内容一致。
